# 竹北、中壢歷史研究筆記

目的：從地理切入，搭配人物與事件，了解竹北與中壢的歷史，並延伸到兩地的特產、食物與農作。

| [02-課本裡的桃竹事件.md](02-課本裡的桃竹事件.md) | 108 課綱國高中歷史課本裡出現的桃竹相關事件，依證據強度分級，附閱讀切入順序 |
| [03-特產食物與農作.md](03-特產食物與農作.md) | 兩地的農作物、特產與飲食，以及它們和地理、歷史的關係 |

## 建議閱讀順序

1. 先讀 02，用課本已有的五個事件當骨架：林爽文與義民、金廣福、淡水廳、北埔事件、中壢事件。
2. 再讀 01 的施添福，建立「漢墾區、保留區、隘墾區」的空間框架。
3. 竹北走李科旻、黃朝進、《新修竹北市志》；中壢走《雙溪行旅》、《雙城舊事》、《新修桃園縣志》開闢志。
4. 最後讀 03，把農作與食物放回地理脈絡：竹北是河口沖積平原，中壢是台地陂塘旱作區。

## 維護方式

- 每本書讀完後在 01 的表格加一欄「讀後筆記」或另開 `讀書筆記/` 資料夾，一本一檔。
- 實地走訪（新瓦屋、義民廟、中壢老街溪、新明市場）可以開 `踏查/` 資料夾，以日期命名。
- 查證狀態用「已確認」「未查證」標示，不要混在一起。
